## PROJECT 12

## Capstone Project: Cloud-Native AI Model Deployment Platform

Specialization: Cloud Native Software Engineering

Duration: 6 months (Capstone-1: 3 months | Capstone-2: 3 months)

Team Size: 4 Students

- 1. Title

Cloud-Native AI Model Deployment Platform

- 2. Aim

Create a cloud-native platform to deploy and manage machine learning models using

containerized services.

- 3. Outcomes

## Capstone-1 Outcomes (Months 1-3)

• Design cloud-native architecture and system components.

• Setup containerized development environment.

• Implement initial microservices and APIs.

## Capstone-2 Outcomes (Months 4-6)

• Deploy services using container orchestration.

• Implement monitoring, logging, and scaling.

• Final system testing and documentation.

5. Team Composition and Role Distribution

## Student 1: Cloud-Native Architect

Primary Responsibilities:

• Design microservices architecture and system topology.

• Define containerization strategy and service communication.

Skills Required: Microservices architecture, system design.

## Student 2: DevOps and Containerization Engineer

Primary Responsibilities:

• Implement Docker containers and Kubernetes deployment.

• Configure CI/CD pipelines for automated deployment.

Skills Required: Docker, Kubernetes, DevOps tools.

## Student 3: Backend Microservices Developer

Primary Responsibilities:

• Develop backend APIs and microservices.

• Implement service communication and data storage.

Skills Required: Backend development, REST APIs, databases.

## Student 4: System Integration and Project Lead

Primary Responsibilities:

• Integrate microservices, infrastructure, and deployment pipelines.

• Perform testing, documentation, and final demonstration.

Skills Required: System integration, testing, documentation.
